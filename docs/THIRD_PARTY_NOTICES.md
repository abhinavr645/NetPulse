# NetPulse dependency and runtime notices

## Application code and icon

The NetPulse source is a college project. No license grant for its own code is
invented by this release; the author/college may choose one before public
redistribution. Student, USN, college and guide fields remain editable in the
report. The simple pulse icon was drawn for this project with Java2D-compatible
geometry/System.Drawing; it uses no third-party artwork or fonts.

for all included third-party runtime components.

## Build/test tools, not shipped as application dependencies

Maven and its plugins build the JAR and stage dependencies. JUnit Jupiter 5.13.4
is used for tests. JDK `jpackage`/`jlink` build the Windows image. Their tool
executables, Maven cache, JUnit, test classes, acceptance-test agent, test
databases, logs and test reports are not included in the release. The runtime
retains the standard `java.instrument` module so the external acceptance agent
can verify the actual launcher; no test agent is shipped or enabled for users.

The unmodified SQLite JDBC JAR includes upstream native libraries for multiple
platforms. Keeping the original JAR preserves its service metadata, native
resource paths and license contents; NetPulse itself targets Windows x64 here.
